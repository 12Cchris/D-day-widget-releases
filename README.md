# D-day

Windows 바탕화면에 항상 떠 있는 투명 D-day 카운트다운 위젯입니다.

## 기능
- 목표 날짜까지 남은 일수(D-day)를 실시간으로 표시
- 시작일 기준 진행률을 프로그레스바로 시각화
- 날짜는 `YYYY-MM-DD` 형식은 물론, `D-100`처럼 입력하면 오늘부터 100일 뒤로 자동 계산
- 제목을 따로 안 정하면 목표 날짜가 자동으로 제목 자리에 표시됨
- 제목, 글씨 색상, 진행바 색상, 글씨 크기 자유롭게 커스터마이즈
- 드래그로 위치 이동, 설정은 자동 저장
- 우클릭 메뉴에서 모든 설정 변경, 설정 초기화, 버전 정보 확인 가능
- 한국어 / English 언어 선택 지원
- 새 버전이 나오면 자동으로 감지해서 다운로드 및 설치까지 진행 (관리자 권한 불필요)

## 설치
[Releases]([https://github.com/12Cchris/D-day-widget/releases](https://github.com/12Cchris/D-day-widget-releases/releases)) 페이지에서 최신 `D-day_Setup.exe`를 다운로드해서 실행하세요. 관리자 권한 없이 설치되며, 이후 새 버전이 나오면 위젯이 알아서 업데이트를 안내합니다.

## 사용법
- **좌클릭 드래그**: 위젯 위치 이동
- **우클릭**: 설정 메뉴 열기
  - 제목 변경 / 목표 날짜 변경 / 시작일 변경
  - 글씨 색상 변경 / 진행바 색상 변경 / 글씨 크기 변경
  - 진행률 바 표시 여부
  - 언어 (한국어 / English)
  - 설정 초기화
  - 버전 정보
  - 업데이트 확인
  - 프로그램 끄기
- **ESC**: 프로그램 즉시 종료
